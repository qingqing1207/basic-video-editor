# 轨道管理

在抽离的编辑器中新增：

- 时间轴左上角 `Add track`：新增视频／图片、文字、音频空轨道。
- 每条轨道左侧 `…`：上移、下移、在上方／下方新增同类型轨道、整轨删除。轨道空白处的右键菜单提供相同操作。
- 上移／下移与相邻轨道交换位置，允许跨主轨和不同类型轨道。视觉轨道越靠上，合成时越靠前。
- 主动新增且未参与移动的空轨道不被自动清理；本次片段移动留下的源空轨道在同一命令内移除，详见 [移动清理规则](opencut-changes/track-move-cleanup.md)。删除整轨同时删除其中片段，不删除素材库里的源文件。支持撤销／重做。

## 数据与实现

`TimelineTracks.order` 持久化从上到下的轨道 ID。`getOrderedTracks` 统一用于轨道行、标签、拖放命中、组移动、粘贴、渲染与画布命中测试。片段与轨道 ID 不因上下换位而改变，片段的起始时间、裁剪、关键帧等保持不变。

结构仍保留一个视频主轨作为原版时间处理的锚点。删除主轨时，优先提升现有的最下方视频轨，不改变其位置或片段；如果已经没有视频轨，保留一个新的空视频轨。最后一条视频轨删除后因此会出现空轨，其他类型轨道可全部删除。

`editor.timeline.addTrack({ type, index? })` 使用显示位置索引；`moveTrack({ trackId, index })` 移到指定显示位置；`removeTrack({ trackId })` 删除整轨。这些操作均进入原命令历史。删除轨道清除该轨道上的片段、关键帧与蒙版点选择，撤销时恢复选择。

## 验证记录

自动化检查覆盖：

- 跨主轨／音频换位，不改变片段对象、时间和轨道身份，撤销／重做。
- 空轨道经过其他编辑仍存在。
- 删除有内容的主轨、提升已有视频轨、撤销恢复片段与选择。
- 删除最后一条视频轨时的空锚点及重做 ID 稳定性。
- 换位后的拖放索引和实际插入目标一致。
- 预览、导出场景节点与画布命中使用同一叠放顺序。
- 工程存储保存、读取 `order`。

浏览器验收（Chromium 桌面，2026-10-05）：

- Vite：新建三种类型空轨道；音频跨过主轨与文字轨；图片、视频通过真实鼠标拖入指定轨道；视频主轨移动到最上方后画布遮挡正确。
- 删除有片段的主轨后，剩余图片轨正确显示，素材库视频仍保留；立即 Cmd+Z 恢复视频、轨道顺序、原片段选择和属性面板。
- 轨道空白处右键，在上方新增同类型轨道；新增可立即撤销。第一行上移／末行下移禁用，文字轨不显示静音操作。
- 换位和 Esc 关闭菜单后焦点保持在编辑器内；菜单操作后可立即撤销。
- 自动保存完成后重新打开工程，恢复 `[主视频、图片、音频、空文字]` 顺序、三个素材与 1 秒播放头。
- MP4：H.264 + AAC，240×160，视频 6 秒，总时长 6.083628 秒，155901 bytes。
- WebM：VP9 + Opus，240×160，总时长 6.02 秒，164426 bytes。
- 两种导出均用 FFmpeg 解码第 1 秒帧，确认顶层显示换位后的主视频，而不是下面的图片。
- Next 生产构建：通过同一包产物新增视频轨、下移跨主轨、删除、立即撤销，操作正常。
- 108 项自动化测试、编辑器及两种示例构建、包审计通过；独立压缩包消费者另外验证类型及构建。

证据：`artifacts/track-management.png`、`track-management-next.png`、`track-management.mp4`、`track-management.webm` 及对应解码帧。
