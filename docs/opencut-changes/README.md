## 对话溯源与最终决策

下列引文是本次对话中的用户原话节选；按对话顺序排列。旧记录中的日期来自既有文档，不为缺少时间戳的消息补造精确时间。

| 顺序 | 用户提出的需求／问题 | 最终落地与分类 |
| --- | --- | --- |
| 1 | “只保留本地剪辑能力”“ui完整换成baseui”“方便集成、拓展” | 独立 React 编辑器包、本地适配器、Base UI、Vite/Next 实际产物集成；属于产品抽离与封装，不是新增剪辑算法 |
| 2 | “素材无法拖动到轨道” | 修复样式隔离后的拖动预览 portal，连带补齐拖动生命周期；属于迁移回归 |
| 3 | “没办法缩放时间轴了” | 修复 Base UI Slider 单值回调适配和 NaN 污染；属于迁移回归 |
| 4 | “参考opencut做一个项目管理页面……不要放在header中” | 复刻原项目页，导出可选 ProjectBrowser；移除示例测试工具栏，并补齐确认、失败与复制处理 |
| 5 | “删除Replace media（替换素材）所有相关的功能” | 删除未实现的菜单及替换素材拖放预留链路；Reveal media 保留 |
| 6 | 多场景入口讨论后：“删除全部相关的功能”“不需要兼容，直接删除数据” | 单时间线 version 2，删除多场景 API/UI/存储结构；当时按授权清理示例数据。本轮不再删除用户数据 |
| 7 | “素材的比例会被改变……按原比例展示” | 时间线平铺缩略图改为等比缩放，图片和视频都适用；不是新做按时间抽帧 |
| 8 | “这个freeze的功能全部删掉” | 删除 Freeze frame 占位入口；原版未实现的能力，不是删掉已有定格处理引擎 |
| 9 | “轨道没办法直接删除、直接新增，没办法往下移动” | 新增轨道按钮、轨道菜单和右键操作、持久化显示顺序及合成顺序支持 |
| 10 | “每换一次位置，都会新增一条轨道……多了很多空轨道” | 定位到原版片段拖动的新建轨道分支与我们移除全局空轨清理后的组合回归 |
| 11 | “保持当前的规则不变……删除原来的空白轨道……界面不能感知” | 保留现有拖放算法，在同一移动命令中计算并移除源空轨道，再一次提交 |
| 12 | “多选或联动移动……判断原来的轨道是不是空了需要删除” | 扩展为所有实际参与本次移动的源轨道，按最终是否为空判断；不再限制移动前片段数 |
| 13 | “最终效果是对的，但是指示线还是在下面” | 指示线移入轨道滚动内容，统一留白与展开行高度；不改变拖放规则 |
| 14 | “导出按钮的样式换成符合主题的扁平按钮” | 顶部 Export 复用统一 Button，删除多层渐变、高光、固定蓝色及立体阴影，使用主题主色与前景色；导出参数与流程不变。编辑器及 Vite/Next 构建通过，浏览器验证明暗外观、点击和 Enter 打开、Esc 关闭。效果见 [截图](../evidence/export-button-flat.png)，源码为 `packages/editor/src/components/editor/export-button.tsx` |
| 15 | “统一样式主题……方便直接替换主题……变量token化”“开始实现” | 统一主题清单与类型、appearance/density API、基础组件和时间线外观、外部浮层继承及 Canvas 重绘；保留项目内容和轨道几何边界。见 [实施与验收](./theme-system.md) |

## 不属于已交付功能的讨论

- 未实施“拖一个片段自动交换整条轨道”。
- 未实施“重叠就不可放置”的新限制，仍保留原插入／新建轨道规则。
- 未新增整轨拖动手柄；已有上移／下移菜单继续保留。
- dnd-kit 曾为手柄方案准备安装，但最终方案不需要，已移除该依赖。
- Ad Genie 集成、生成视频下载后交给编辑器等属于接入讨论；本任务没有修改 Ad Genie，也没有开发远程视频后台。
- createEditor 与 VideoEditor 的关系、WASM 作用等解释，不计作新增功能。

## 状态与证据约定

“已有实现”以当前源码和具体测试记录为依据；既有验收引用旧记录，本次没有重新运行的操作不会写成已复验。迁移引入的 bug 单独登记，不归咎于原版。源码存在、构建通过和交互通过分别记录。

整体抽离仍有 [未覆盖范围](../interaction-baseline.md)，尤其是系统文件原生拖放、真实 OS 输入法、Firefox 和复杂组合，不用本目录替代完整验收。新增变更时补充：需求来源、原版行为、最终行为、源码入口、验证及限制。
